# Voice (default)

> Tone, vocabulary, and the substance rule live in the shared
> `skills/_shared/substance-voice.md` (override at `docs/marketing/substance-voice.md`).
> The anti-tell rules live alongside it in `skills/_shared/human-voice.md`.
> This file keeps only the per-post structure.

## The beats a post usually covers

1. Hook — the pain or surprising claim.
2. Context — 1–2 sentences grounding the reader.
3. Mechanism — what we did / how it works.
4. Outcome — concrete change for the user.
5. CTA — single, explicit action.

## This is guidance, not a form

The order above is a default, not a required sequence, and a post does not have to
hit every beat. Vary it deliberately:

- Open on the number when the number is the story ("Sync went from 8s to 400ms.").
- Open on the objection when readers are sceptical ("You probably turned this off
  last year. Here's what changed.").
- Open flat when the feature speaks for itself — no hook at all.
- Drop Context for an audience that already has it.
- Merge Mechanism and Outcome when they are one sentence.

Every post following Hook → Context → Mechanism → Outcome → CTA is itself a tell,
independent of how good the individual sentences are. Someone who reads three of
your posts should not be able to predict the shape of the fourth.
