# Caption Templates (default)

> Embedded default. Override at `docs/marketing/caption-templates.md`.

These are shapes, not forms. The bullet count is variable by design — see the
note at the bottom.

## Instagram

```
{HOOK}

{CONTEXT — 1 sentence}

{VALUES_2_TO_4 — plain lines or hyphens, no decorative glyphs}

{CTA}

{HASHTAGS}
```

## LinkedIn

```
{HOOK}

{CONTEXT — 2–3 sentences}

{LEAD-IN LINE — vary it; "What we shipped:" on every post is a tell}

{POINTS_2_TO_4}

{OUTCOME — 1–2 sentences, quantified when possible}

{CTA with link}
```

## X (first tweet)

```
{HOOK — ≤ 240 chars}
```

## On the bullet count

Write the number of points the feature actually has. Two is fine. Four is fine.
One strong line and no list at all is fine.

Three was the old default because the template had three slots — and a launch
history where every post carries exactly three bullets reads as generated even
when every individual line is good. Vary it deliberately across a campaign.
